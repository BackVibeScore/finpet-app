# UX/UI-доработка v4

Изменён только интерфейс существующего проекта.

- На главном экране: питомец и состояние, текущая ситуация, баланс и срок дохода, цель, действия, дополнительный прогресс мира.
- Убран повтор баланса в шапке главного экрана.
- Подработка вынесена из тесного ряда в отдельную кнопку с условиями и статусом продолжения смены.
- Увеличены мелкие подписи, контраст текста и области нажатия; снижены тени.
- Подработка: сокращены объяснения, условия работы собраны в три поля.
- Добавлены выделение клавиатурного фокуса, обозначение текущего раздела для скринридера, подпись кнопки питомца и поддержка reduced motion.
- Обновлён ключ кеша приложения для загрузки новых стилей.

Проверка этой доработки: синтаксис JS, runtime_smoke, side_job_smoke и gameplay_smoke пройдены. Экономика, состояние, сохранения и контент механик не изменены. Визуальная проверка в браузере не выполнена: исполняемый файл Chromium отсутствует в среде. Старый TEST_REPORT описывает предшествующий этап, а не визуальную проверку этой доработки.


## Упрощение поверхностей
Убраны повторяющиеся обводки карточек и сверхжирные начертания 800–950. Заголовки 600, обычные строки 400, элементы управления 500. Настройки оформлены строками с переключателями role=switch, без финансовой шапки. Выбранные цели и фокус управления остаются различимыми. Логика переключателей и подтверждение сброса сохранены.
