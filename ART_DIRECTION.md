# Визуальный стиль и происхождение графики

Палитра: молочный `#F8F5EE`, хвойный `#285441`, терракота `#AD562F`. Основной шрифт — Segoe UI с системным sans-serif fallback. Внешние CDN и удалённые шрифты не используются.

## Растровые ассеты

- `assets/objects.webp` — предметный атлас;
- `assets/extras.webp` — дополнительные предметы;
- `assets/worlds.webp` — сцены Дома, Парка и Города.

Ассеты были созданы специально для проекта встроенным инструментом OpenAI ImageGen, затем оптимизированы в WebP. Исходная стилистика: матовая гуашь/карандаш, кремово-хвойно-терракотовая палитра, без текста и emoji. Постоянное интернет-соединение не требуется.

## Векторная графика v5

Иллюстрации знакомства, помощи, цифровой безопасности, взрослого раздела, подтверждений и пустых состояний создаются локально функцией `learningArtwork()` как оригинальные inline SVG. Аксессуары питомца также являются кодовыми SVG-элементами.

Декор имеет `aria-hidden="true"`, `focusable="false"` и `pointer-events: none`. Значимые действия всегда имеют текстовую подпись.

## Лицензирование

В проекте нет сторонних скачанных иллюстраций. WebP-ассеты созданы для данного проекта средствами OpenAI и используются по применимым условиям сервиса. Inline SVG и интерфейсный код являются частью исходников проекта. Системный шрифт не распространяется вместе с приложением.
