# Происхождение и использование графических ресурсов

| Файл или элемент | Источник | Использование |
|---|---|---|
| `assets/objects.webp` | Создан специально для проекта с использованием OpenAI ImageGen | В составе проекта |
| `assets/extras.webp` | Создан специально для проекта с использованием OpenAI ImageGen | В составе проекта |
| `assets/worlds.webp` | Создан специально для проекта с использованием OpenAI ImageGen | В составе проекта |
| `assets/onboarding-*.webp` | Созданы специально для проекта с использованием OpenAI ImageGen | В составе проекта |
| WebP-изображения товаров и целей | Созданы специально для проекта | В составе проекта |
| SVG-питомец и аксессуары | Оригинальный код проекта | В составе исходников |
| SVG-иллюстрации интерфейса | Оригинальный код проекта | В составе исходников |
| Segoe UI / system sans-serif | Системный шрифт устройства | Файлы шрифтов не включаются в проект |

Внешние изображения, CDN и графические зависимости, загружаемые во время работы приложения, не используются.

Системные шрифты не распространяются вместе с приложением. Использование материалов, созданных средствами OpenAI, регулируется применимыми условиями соответствующего сервиса.
