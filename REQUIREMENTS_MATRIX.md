# Матрица соответствия требованиям

Документ связывает требования конкурсной задачи с реализованными функциями, файлами и автоматическими проверками.

## Функциональные требования

| Требование | Статус | Реализация | Подтверждение |
|---|---|---|---|
| Мобильное приложение | Реализовано | Android-оболочка на Capacitor, package `ru.kopihvost.app` | `android/`, `capacitor.config.json`, `BUILD_ANDROID.md` |
| Возможность выбрать и создать виртуального питомца | Реализовано | Кот, собака и Мумо, имя, цвет и аксессуар | `content.js`, `app.js` |
| Забота о питомце | Реализовано | Еда, настроение, здоровье, энергия, покупки и быстрые действия | `app.js`, `content.js`, `tests/critical_pet_needs_smoke.js` |
| Использование виртуальной валюты | Реализовано | Единый баланс, журнал операций, расходы, доходы и накопления | `app.js`, `tests/gameplay_smoke.js` |
| Необходимость зарабатывать и распределять ресурсы | Реализовано | Периодический доход, награды за задания, подработка в усложненном режиме, недельное планирование | `app.js`, `content.js` |
| Планирование бюджета | Реализовано | Подтвержденный план с категориями «нужно», «хочу», «коплю» и резервом | `app.js`, `tests/web_competition_requirements_smoke.js` |
| Приоритизация расходов | Реализовано | Необходимые и необязательные расходы влияют на бюджет и состояние питомца | `app.js`, `content.js` |
| Формирование накоплений | Реализовано | Копилка, выбор финансовой цели, прогноз срока достижения | `app.js`, `content.js` |
| Финансовые задания | Реализовано | Набор заданий по бюджету, скидкам, резерву, кредиту, регулярным расходам и финансовой безопасности | `content.js`, `tests/validate_content.js` |
| Цифровая финансовая безопасность | Реализовано | Темы кодов, фишинга, сомнительных ссылок, файлов, дропперства и защиты аккаунта | `content.js` |
| Прогресс питомца зависит от финансовых решений | Реализовано | Развитие начисляется по итогам периода за покрытие нужного, соблюдение плана, накопления и сохранение резерва | `app.js`, `tests/web_competition_requirements_smoke.js` |
| Последствия решений видны игроку | Реализовано | Финансовая обратная связь, изменение баланса, питомца, копилки, целей и мира | `app.js` |
| Разные уровни сложности | Реализовано | Режимы `easy` и `medium` | `app.js`, `tests/v6_requirements_smoke.js` |
| Демонстрационный сценарий | Реализовано | Отдельный режим из пяти периодов с пошаговыми подсказками | `app.js`, `tests/web_competition_requirements_smoke.js` |
| Сохранение прогресса | Реализовано | Локальное состояние, резервная копия и Capacitor Preferences на Android | `storage.js`, `tests/storage_adapter_smoke.js` |
| Работа без обязательной регистрации | Реализовано | Профиль создается локально | `app.js`, `storage.js` |
| Отсутствие реальных финансовых операций | Реализовано | Используется только игровая валюта | `app.js`, `STORE_METADATA.md` |

Основные конкурсные сценарии покрывает `tests/web_competition_requirements_smoke.js`.
