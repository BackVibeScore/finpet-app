# КопиХвост — отчёт проверки

Дата актуализации: 27.09.2026.

## Объект проверки

Актуальный `main` проекта «КопиХвост»: веб/PWA-версия и Android-контур на Capacitor.

Текущая модель состояния — version 6. Ключ хранения `finpet_mvp_state_v1` сохранён для совместимости с предыдущими версиями.

## Автоматический контур

В репозитории настроены два workflow:

- `Web validation`;
- `Android APK validation`.

Они проверяют синтаксис JavaScript, игровой runtime, недельный цикл и экономику, миграции state, режимы сложности, демо-сценарий, движение/анимацию, бренд, контент, аналитику, repository hygiene, Android storage adapter и Android build.

Дополнительные web-проверки покрывают конкурсный демо-сценарий, детские тексты и цели, занятия, критические потребности питомца, систему здоровья и представление товаров.

## Проверяемые продуктовые сценарии

- локальный профиль и миграция сохранений;
- Лёгкий / Средний режим;
- Демо из 5 последовательных периодов;
- планирование бюджета;
- необходимые и необязательные расходы;
- невозможность уйти в отрицательный баланс;
- подтверждение покупки;
- копилка и подтверждение снятия;
- финансовые цели;
- задания и награды без повторного начисления;
- последствия решений и единый feedback;
- рост питомца по итогам периода;
- защита взрослого раздела арифметической проверкой;
- сохранение прогресса;
- Android-сборка без Яндекс.Метрики и без обязательного INTERNET permission.

## Android persistence

Автоматическими smoke-тестами проверяется adapter, использующий:

```
Capacitor Preferences current
→ native backup
→ localStorage compatibility layer
→ новый профиль
```

Финальная ручная проверка должна подтвердить сохранение после:

1. обычного закрытия и повторного запуска;
2. force stop;
3. перезагрузки устройства;
4. установки новой версии APK поверх существующей.

## Mobile UI

Подготовлен сценарий проверки мобильных размеров 320, 360, 390 и 430 px.

Автоматическая проверка DOM/CSS не заменяет ручную визуальную приёмку на реальном устройстве.

## Что остаётся перед финальной конкурсной сдачей

- физический тест финального APK;
- финальная визуальная приёмка;
- подписанная release-сборка;
- проверка установки обновления поверх предыдущей версии;
- финальная проверка store-материалов и ссылок для экспертов.

Для версии 0.1.1 автоматические Web validation и Android APK validation завершены успешно. Подписанная release-сборка подготовлена отдельно от репозитория; физическая проверка на Android-устройстве остаётся обязательным финальным шагом.
