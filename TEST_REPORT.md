# Проверка проекта «КопиХвост»

Дата актуализации: 28.09.2026.

## Что проверяется

Проверки охватывают актуальную ветку `main`: веб/PWA-версию и Android-проект на Capacitor.

Текущая версия структуры состояния — **6**. Ключ `finpet_mvp_state_v1` сохранён для совместимости с предыдущими версиями.

## Автоматические проверки

В репозитории настроены два GitHub Actions workflow:

- `Web validation`;
- `Android APK validation`.

Автоматические тесты проверяют:

- синтаксис JavaScript;
- основной игровой цикл;
- экономику и переход между периодами;
- миграцию сохранений;
- режимы сложности;
- демонстрационный сценарий;
- анимацию и её отключение;
- образовательный контент;
- аналитику;
- структуру репозитория;
- Android-хранилище;
- подготовку Android-сборки.

Дополнительные тесты покрывают детские тексты и цели, занятия, критические потребности питомца, систему здоровья, представление товаров и ключевые конкурсные сценарии.

## Продуктовые сценарии

Проверяются следующие действия пользователя:

- создание и восстановление локального профиля;
- выбор Лёгкого или Среднего режима;
- прохождение Демо-режима из пяти периодов;
- планирование бюджета;
- обязательные и необязательные расходы;
- запрет отрицательного баланса;
- подтверждение покупок;
- пополнение копилки и снятие средств;
- постановка финансовых целей;
- выполнение заданий без повторного начисления награды;
- реакция игры на финансовые решения;
- развитие питомца;
- вход в раздел «Для взрослых»;
- сохранение прогресса между запусками;
- подготовка Android-версии без Яндекс.Метрики.

## Проверка сохранений на Android

Используется следующая последовательность восстановления:

```text
Capacitor Preferences
→ резервная копия
→ localStorage
→ новый профиль
```

На физическом Android-устройстве необходимо дополнительно проверить сохранение после:

1. обычного закрытия и повторного запуска;
2. force stop;
3. перезагрузки устройства;
4. установки новой версии APK поверх существующей.

## Мобильный интерфейс

Подготовлены проверки для ширины экрана 320, 360, 390 и 430 px.

Автоматическая проверка DOM и CSS не заменяет финальную визуальную приёмку на реальном устройстве.

## Финальная проверка перед публикацией

Перед публикацией необходимо:

- протестировать финальный APK на физическом устройстве;
- провести визуальную приёмку основных экранов;
- проверить установку обновления поверх предыдущей версии;
- сформировать подписанную release-сборку;
- проверить карточку приложения и доступность материалов для экспертов.

Автоматические проверки версии 0.1.1 используются как базовый регрессионный контур проекта.
