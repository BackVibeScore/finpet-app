# КопиХвост

Игровое offline-first приложение по финансовой грамотности для детей 7–11 лет.

Слоган: **«Твой питомец. Твои деньги. Твои решения.»**

Проект создан для конкурсного задания ЛЦТ 2026. Основной сценарий учит распределять ограниченный бюджет между необходимыми расходами, желаниями и накоплениями, видеть последствия решений и развивать виртуального питомца.

## Что реализовано

- локальный профиль без обязательной регистрации, имени, телефона и e-mail;
- два уровня сложности: **Лёгкий** и **Средний**;
- отдельный **Демо**-режим из 5 последовательных игровых периодов;
- выбор питомца, цвета, имени и аксессуара;
- единый кошелёк и журнал транзакций;
- недельное планирование бюджета;
- необходимые и необязательные покупки;
- копилка и финансовые цели;
- задания по финансовой грамотности и цифровой безопасности;
- игровые события и последствия решений;
- развитие питомца и игрового мира по итогам периодов;
- история операций, помощь и раздел «Для взрослых»;
- защита взрослого раздела простой арифметической проверкой;
- сохранение прогресса после закрытия приложения.

## Архитектура

Приложение использует одно общее frontend-ядро:

```
index.html
styles.css
content.js
app.js
welcome.js
storage.js
analytics.js
assets/
```

`content.js` хранит учебный и игровой контент.  
`app.js` содержит игровую логику, экономику, навигацию и UI.  
`storage.js` отвечает за совместимое локальное хранение и резервное восстановление.  
`welcome.js` отвечает за стартовый экран и вводное знакомство.

Исторические возрастные метаданные `7-11 / 12-14 / 15-17` внутри контента сохранены как слой совместимости. В пользовательском интерфейсе возрастные режимы больше не используются: контент объединяется в режимы `easy / medium`.

## Сохранения

Ключ совместимости:

```
finpet_mvp_state_v1
```

Текущая версия state: **6**.

В браузере состояние хранится локально. В Android основным долговременным слоем являются Capacitor Preferences; `localStorage` остаётся синхронным mirror-слоем для совместимости.

Порядок восстановления на Android:

```
native current → native backup → localStorage → новый профиль
```

Сброс профиля удаляет локальное состояние. Между устройствами синхронизации нет.

## Android

Android-оболочка построена на Capacitor.

- applicationId: `ru.kopihvost.app`;
- минимальная версия: Android 8.0 / API 26;
- ориентация: portrait;
- runtime-файлы и изображения входят в APK;
- основной игровой цикл не требует подключения к интернету;
- Яндекс.Метрика удаляется из Android-сборки;
- AppMetrica пока не подключена.

Сборка:

```bash
npm ci
npm run android:apk
```

Подробно: [BUILD_ANDROID.md](BUILD_ANDROID.md).

## Веб-версия

Веб-версия работает как PWA и использует service worker для offline cache после первого открытия.

Публичная веб-сборка может использовать Яндекс.Метрику. Это веб-аналитика и она не попадает в Android APK.

## Проверки

Основные проверки находятся в `tests/`:

- синтаксис и runtime;
- экономика и недельный цикл;
- миграция сохранений;
- демо-режим;
- покупки, цели, накопления и недостаток средств;
- здоровье питомца;
- задания и контент;
- взрослый раздел;
- бренд и repository hygiene;
- Android bundle и persistence adapter;
- конкурсные требования веб-прототипа.

GitHub Actions:

- `Web validation`;
- `Android APK validation`.

Финальный релиз дополнительно требует ручной визуальной проверки и теста APK на физическом Android-устройстве.

## Безопасность репозитория

В Git не должны попадать ключи подписи, пароли, токены, `.env`, `.jks`, `.keystore`, `local.properties` и другие секреты. Такие файлы исключены через `.gitignore`.

Перед конкурсной сдачей необходимо подготовить подписанный release APK, финальный release/tag, проверить установку на физическом устройстве и убедиться, что ссылки доступны экспертам.
