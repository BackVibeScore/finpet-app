# КопиХвост

**КопиХвост** — игровое приложение по финансовой грамотности для детей 7–11 лет.

Ребёнок выбирает виртуального питомца и отвечает за его жизнь: еду, здоровье, развлечения и развитие. Для этого нужно зарабатывать игровые монеты, планировать бюджет, отличать обязательные расходы от желаний, откладывать на цели и принимать решения в условиях ограниченных ресурсов.

**Слоган:** «Твой питомец. Твои деньги. Твои решения.»

КопиХвост не превращает финансовую грамотность в набор тестов. Обучение встроено в игровой цикл: решение влияет на кошелёк, состояние питомца и развитие его мира, поэтому финансовые последствия становятся понятными через собственный опыт.

Проект разработан для задачи №6 конкурса «Лидеры цифровой трансформации 2026».

## Как работает игра

Игровой цикл построен вокруг нескольких простых действий:

1. ребёнок получает игровой доход;
2. распределяет деньги между необходимыми расходами, желаниями и накоплениями;
3. заботится о питомце и выполняет задания;
4. сталкивается с игровыми событиями и последствиями своих решений;
5. завершает период и видит, как его финансовое поведение повлияло на питомца и игровой мир.

Для экспертной демонстрации предусмотрен отдельный режим из пяти последовательных периодов, который проводит пользователя по ключевым механикам продукта.

## Основные возможности

- виртуальный питомец с выбором персонажа, имени, цвета и аксессуара;
- два уровня сложности: **Лёгкий** и **Средний**;
- отдельный **Демо-режим** для последовательного прохождения основных механик;
- игровой кошелёк и история операций;
- планирование бюджета на период;
- обязательные и необязательные расходы;
- копилка и финансовые цели;
- задания по финансовой грамотности и цифровой безопасности;
- дополнительные способы заработать игровые монеты;
- события и последствия финансовых решений;
- здоровье, настроение и развитие питомца;
- изменение игрового мира по мере прогресса;
- раздел «Для взрослых»;
- локальное сохранение прогресса без обязательной регистрации;
- отсутствие реальных платежей и банковских операций.

## Быстрый запуск веб-версии

Для просмотра достаточно локального HTTP-сервера.

Например, через Python:

```bash
python -m http.server 8080
```

После запуска откройте:

```text
http://localhost:8080
```

Основная веб-версия не требует сборки.

## Структура проекта

Основное приложение использует единое HTML/CSS/JavaScript-ядро:

```text
index.html
styles.css
content.js
app.js
welcome.js
welcome.css
storage.js
analytics.js
assets/
```

Назначение ключевых файлов:

- `content.js` — игровой и образовательный контент;
- `app.js` — игровая логика, экономика, навигация и интерфейс;
- `storage.js` — сохранение, восстановление и совместимость данных;
- `welcome.js` — стартовый экран и вводное знакомство;
- `sw.js` — кэширование веб-версии;
- `assets/` — локальные графические ресурсы.

Возрастные идентификаторы `7-11 / 12-14 / 15-17` внутри части контента сохранены только для совместимости с предыдущими версиями. В актуальном интерфейсе используются режимы `easy / medium`.

## Сохранение данных

Ключ совместимости:

```text
finpet_mvp_state_v1
```

Текущая версия структуры состояния: **6**.

В браузере прогресс хранится локально. В Android основным долговременным хранилищем выступает Capacitor Preferences, а `localStorage` используется как совместимый локальный слой для существующей игровой логики.

Порядок восстановления данных на Android:

```text
Capacitor Preferences
→ резервная копия
→ localStorage
→ новый профиль
```

Синхронизация между устройствами в текущей версии не предусмотрена.

## Android

Android-версия построена на Capacitor и использует то же игровое ядро, что и веб-версия.

- applicationId: `ru.kopihvost.app`;
- versionName: `0.1.1`;
- versionCode: `2`;
- минимальная версия: Android 8.0 / API 26;
- ориентация: portrait;
- игровые файлы и изображения включаются в APK;
- основной игровой сценарий работает без обязательного подключения к интернету;
- Яндекс.Метрика исключается из Android-сборки;
- AppMetrica в текущей версии не подключена.

Сборка debug APK:

```bash
npm ci
npm run android:apk
```

Подробная инструкция: [BUILD_ANDROID.md](BUILD_ANDROID.md).

## Веб-версия

Веб-версия поддерживает установку как PWA. Service worker кэширует необходимые ресурсы после первого открытия.

Публичная веб-версия может использовать Яндекс.Метрику. Этот код исключается при подготовке Android-сборки.

## Проверки

Автоматические проверки находятся в каталоге `tests/` и покрывают:

- игровой цикл и экономику;
- миграцию сохранений;
- режимы сложности и демонстрационный сценарий;
- покупки, накопления и финансовые цели;
- критические потребности и здоровье питомца;
- задания и образовательный контент;
- взрослый раздел;
- мобильную адаптацию;
- подготовку Android-пакета и сохранение данных;
- базовую чистоту репозитория.

В GitHub Actions настроены:

- `Web validation`;
- `Android APK validation`.

Автоматические тесты дополняются ручной проверкой интерфейса и финального APK на физическом Android-устройстве.

## Безопасность репозитория

Ключи подписи, пароли, токены, `.env`, `.jks`, `.keystore`, `local.properties` и другие секреты не должны попадать в Git. Соответствующие файлы исключены через `.gitignore`.

Релизный APK формируется отдельно от исходного репозитория.
