# КопиХвост v5

Мобильное offline-first приложение о финансовой грамотности для детей и подростков. Текущая версия использует единый недельный цикл, кошелёк и `Transaction`, а покупки, накопления, цели, питомец, события, задания, развитие мира и подработка работают как одна игровая система.

## Что есть в приложении

- возрастные режимы без пересечений: `7–11`, `12–14`, `15–17`;
- короткое пропускаемое знакомство с понятиями «Нужно», «Хочу», «Коплю», «Оставлю»;
- питомец, три локации, покупки и пять этапов развития мира;
- недельный доход, планирование бюджета, план/факт и последствия решений;
- единая история транзакций;
- копилка, финансовые цели и приблизительный срок накопления;
- задания по финансовым темам и цифровой безопасности;
- 40 ситуаций/событий, отложенные платежи и сюжетные цепочки;
- добровольная подработка только для режима `15–17`;
- справочник с короткими примерами и повторным запуском знакомства;
- раздел «Для взрослых» с трёхсекундным удержанием кнопки;
- PWA и локальная работа после первого открытия.

## Безопасные финансовые действия

Покупка из интерфейса сначала открывает подтверждение. Списание происходит только после нажатия «Купить» и проводится существующей функцией `buyItem()` через `Transaction`.

Снятие из копилки сначала показывает сумму, остаток, расстояние до цели и старый/новый прогноз срока. После подтверждения используется существующий тип транзакции `saving_withdrawal`. Автоматическое снятие из копилки при покупке не выполняется.

## Возраст и миграция

Ключ хранения не изменён: `finpet_mvp_state_v1`.

Текущая версия state — 5. Миграция сохраняет баланс, накопления, цели, покупки, инвентарь, задания, питомца, мир, события, обязательства, историю транзакций и недель.

- старый `8–10` автоматически становится `7–11`;
- для старых `11–13` и `14–17` один раз открывается уточнение возраста;
- уточнение меняет только `ageGroup` и доступный слой контента;
- старые аксессуары `none`, `cap`, `scarf`, `badge` продолжают работать.

## Контент v5

- 3 вида питомца × 5 цветов × 8 аксессуаров;
- 25 заданий, из них 10 по цифровой безопасности;
- минимум 6 младших сценариев безопасности: код, подозрительная ссылка, неизвестный файл, фальшивый выигрыш, поддельное сообщение знакомого, всплывающие окна;
- отдельные старшие темы: двухфакторная защита, публичный Wi‑Fi, разрешения приложений, поддельные финансовые сайты, удалённый доступ, дропперство и мошеннические инвестиции;
- 20 покупок, 5 целей, 40 событий и 5 этапов мира.

## Структура

- `index.html` — оболочка приложения;
- `styles.css` — интерфейс и адаптивные правила;
- `content.js` — игровой и обучающий контент;
- `app.js` — state, миграция и игровая логика;
- `assets/` — локальные WebP-атласы;
- `manifest.json`, `sw.js` — PWA и offline cache;
- `tests/` — smoke-, migration-, content-, analytics- и mobile-проверки;
- `scripts/build-standalone.js` — сборщик автономного HTML;
- `CHANGELOG.md` — история изменений;
- `TEST_REPORT.md` — результаты проверки;
- `KNOWN_LIMITATIONS.md` — известные ограничения;
- `ART_DIRECTION.md` — визуальный язык и правила графики;
- `ASSET_LICENSES.md` — происхождение графики.

## Запуск

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Для Vercel используется пресет `Other`, корневая директория `.`, без команды сборки.

## Проверки

```bash
node --check app.js
node --check content.js
node --check sw.js
node tests/runtime_smoke.js
node tests/gameplay_smoke.js
node tests/side_job_smoke.js
node tests/v5_requirements_smoke.js
node tests/validate_content.js
node tests/validate_analytics.js
node tests/simulate_strategies.js
```

Визуальная проверка при наличии установленного Playwright Chromium:

```bash
node tests/visual_mobile_check.js
```

Скрипт проверяет ширины 320, 360, 390 и 430 px, отсутствие горизонтальной прокрутки, сценарии знакомства, создания питомца, главного экрана, подтверждений, справочника и раздела для взрослого.

## Standalone

```bash
node scripts/build-standalone.js
```

Результат создаётся локально в `dist/finpet_demo_v5.html`. Папка `dist/` считается производной сборкой и не хранится в Git. Standalone HTML содержит CSS, JavaScript и WebP-изображения внутри файла и не требует сервера.

Android-контур реализован через Capacitor из тех же исходников. Debug APK и unsigned release APK собираются GitHub Actions; инструкция — `BUILD_ANDROID.md`. Игровые файлы упаковываются внутрь APK, Яндекс.Метрика в Android build отсутствует.
